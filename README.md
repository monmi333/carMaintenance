# CarCare 정비센터 — 자동차 정비 관리 웹 애플리케이션

외부 패키지 없이 **Python 표준 라이브러리만으로** 동작하는 자동차 정비 관리 웹 애플리케이션입니다.

- 정비 항목 목록 조회: 부품명, 작업명, 가격, 권장 교체 km
- 정비 예약: 예약자 정보 입력, 시간대 선택, 결제 시뮬레이션(카드/계좌이체), 취소·환불
- 차량 프로필: 차량 사진 업로드(최대 5MB, 이미지 파일만 허용)
- 마이클 Excel 리포트(.xls) 가져오기: 정비·주유·기타·주행 기록 저장 및 차량별 조회
- 브라우저 UI(HTML/CSS/JS)에서 모든 기능을 바로 사용할 수 있습니다.

## 요구 사항

- Python 3.12 이상 (3.14.7에서 확인)
- `pip install`은 필요 없습니다.

## 디렉터리 구조

```
carMaintenance/
├── server.py           # HTTP 서버 + REST API + SQLite 저장 (진입점)
├── static/
│   ├── index.html      # 단일 페이지 UI
│   ├── style.css
│   └── app.js          # 화면 동작, API 호출
├── uploads/            # 업로드된 차량 사진 (실행 시 자동 생성)
├── data/               # car_maintenance.db (실행 시 자동 생성)
└── README.md
```

## 실행 방법

### Windows

```powershell
cd N:\carMaintenance
python server.py
```

### macOS

터미널에서 프로젝트 폴더로 이동한 다음 `python3`으로 실행합니다. VS Code에서는 **터미널 → 새 터미널**을 열면 됩니다.

```bash
cd ~/Desktop/carMaintenance
python3 server.py
```

브라우저에서 **http://127.0.0.1:8000** 에 접속합니다. 종료하려면 `Ctrl+C`를 누르세요.

포트 변경 옵션:

```powershell
python server.py --port 9000              # 포트 변경
python server.py --host 0.0.0.0           # 같은 네트워크의 다른 기기에서 접속 허용
```

macOS에서는 같은 옵션에 `python3`을 사용합니다.

```bash
python3 server.py --port 9000
python3 server.py --host 0.0.0.0
```

처음 실행하면 `data/car_maintenance.db`가 생성되고 정비 항목 12개가 기본으로 등록됩니다.
예약, 결제, 차량 정보는 이 DB에 저장되므로 서버를 재시작해도 그대로 남습니다.
초기 상태로 되돌리려면 서버를 끄고 `data/` 폴더의 `car_maintenance.db*` 파일(WAL 모드라 `-wal`, `-shm` 포함)을 모두 삭제하세요.

## 브라우저 테스트 시나리오

1. **정비 항목**: 목록에서 가격과 권장 교체 km를 확인하고, 검색창에 `브레이크`를 입력해 결과가 걸러지는지 봅니다. `예약 담기`를 누르면 해당 항목이 체크된 채로 예약 탭으로 이동합니다.
2. **정비 예약**: 이름, 연락처(`010-1234-5678`), 차량번호(`12가3456`), 예약일, 시간, 항목을 고르고 `예약하고 결제하기`를 누릅니다.
   - 이미 예약된 시간대는 취소선으로 표시되어 선택할 수 없습니다.
   - 예약일은 오늘부터 90일 이내만 고를 수 있습니다.
   - 결제하지 않은 예약은 **15분 뒤 자동 취소**되고 시간대가 다시 열립니다.
3. **결제 시뮬레이션** (실제 결제는 일어나지 않습니다)
   - 카드번호 `4111 1111 1111 1234`, 유효기간 `12/30`, CVC `123` → 결제 완료, 승인번호 발급
   - 카드번호가 `0000`으로 끝나면 → **승인 거절**
   - 지난 유효기간(예: `01/20`) → 오류
   - `계좌이체`를 고르고 입금자명을 입력해도 결제가 완료됩니다.
4. **예약 내역**: 상태 배지(결제 대기 / 예약 확정 / 취소됨)를 확인합니다. 결제 대기 건은 `결제하기`로 다시 결제할 수 있고, `취소`(결제 완료 건은 `취소 (환불)`)를 누르면 시간대가 다시 열립니다.
5. **차량 프로필**: 차량번호, 차종, 주행거리를 입력하고 사진을 선택하거나 끌어다 놓은 뒤 저장합니다.
   - 같은 이름의 파일을 다시 올리면 `사진_20261027_153012.png`처럼 타임스탬프가 붙어 저장됩니다.
   - `.exe`, `.bat` 같은 실행 파일은 **"위험한 확장자"** 메시지와 함께 거부됩니다. `photo.exe.png`처럼 중간에 숨긴 경우도 거부됩니다.
   - 그 밖에 이미지가 아닌 파일, 5MB를 넘는 파일, 확장자만 바꾼 가짜 이미지도 오류 메시지와 함께 거부됩니다.
   - 사진을 교체하면 이전 사진 파일은 삭제됩니다.
   - 차량 카드를 클릭하면 수정할 수 있습니다. 이때 사진을 선택하지 않으면 기존 사진이 유지됩니다.
   - 예약의 차량번호와 같은 차량 프로필이 있으면 예약 내역에 차량 사진이 함께 표시됩니다.
6. **마이클 기록 가져오기**: `차량 기록` 탭에서 마이클 앱의 Excel 97-2003 `.xls` 내보내기 파일을 선택해 가져옵니다.
   - 파일의 차량번호·차종·최종 주행거리로 차량 프로필을 만들거나 갱신하고, 정비·주유·기타·주행 시트의 내역을 저장합니다.
   - 같은 파일이나 같은 내역을 다시 가져와도 중복 기록은 건너뜁니다.
   - 차량과 기록 종류를 골라 조회할 수 있으며, 비용 합계와 기록 수, 누적 주행거리를 확인할 수 있습니다.
   - 가져오기는 `.xls`만 지원하며 최대 10MB입니다. 파일 내용은 기록으로 저장하고 업로드 원본은 보관하지 않습니다.

## API

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/api/config` | 업로드 제한, 예약 가능 기간, 결제 기한 등 서버 설정값 |
| GET | `/api/items` | 정비 항목 목록 |
| GET | `/api/slots?date=YYYY-MM-DD` | 날짜별 예약 가능 시간대 (09:00~17:00) |
| GET | `/api/reservations` | 예약 목록 (항목, 결제 정보, 차량 사진 포함) |
| POST | `/api/reservations` | 예약 생성 (JSON) → `PENDING` |
| POST | `/api/reservations/{id}/pay` | 결제 시뮬레이션 (JSON) → `PAID` |
| POST | `/api/reservations/{id}/cancel` | 예약 취소 / 환불 (JSON 본문 `{}`) → `CANCELLED` |
| GET | `/api/vehicles` | 차량 프로필 목록 |
| POST | `/api/vehicles` | 차량 등록·수정 + 사진 업로드 (multipart/form-data) |
| GET | `/api/records?car_number=12가3456&type=정비` | 차량별 정비·주유·기타·주행 기록 |
| POST | `/api/import/michael` | 마이클 `.xls` 내보내기 파일 가져오기 (multipart/form-data, `file` 필드) |

PowerShell 예시 (Windows에서는 PowerShell의 `curl` 별칭 대신 `curl.exe`를 쓰세요):

```powershell
curl.exe http://127.0.0.1:8000/api/items

curl.exe -X POST http://127.0.0.1:8000/api/reservations -H "Content-Type: application/json" `
  -d '{\"customer_name\":\"홍길동\",\"phone\":\"01012345678\",\"car_number\":\"12가3456\",\"reserve_date\":\"2026-12-01\",\"reserve_time\":\"10:00\",\"item_ids\":[1,4]}'

curl.exe -X POST http://127.0.0.1:8000/api/reservations/1/pay -H "Content-Type: application/json" `
  -d '{\"method\":\"card\",\"card_number\":\"4111111111111234\",\"expiry\":\"12/30\",\"cvc\":\"123\"}'

curl.exe -X POST http://127.0.0.1:8000/api/vehicles -F "car_number=12가3456" -F "model=쏘나타" -F "mileage=42000" -F "photo=@car.jpg"
```

오류 응답은 모두 `{"error": "메시지"}` 형식입니다. 상태 코드는 400(입력 오류), 402(결제 거절), 403(다른 사이트에서 보낸 요청), 404, 409(중복 예약·이미 처리됨), 413(5MB 초과), 415(JSON이 아닌 요청)입니다.
예약 목록의 전화번호는 `010-****-5678`처럼 가운데를 가려서 응답합니다.

## 구현 메모

- **업로드 검증**: 확장자 허용 목록(jpg, jpeg, png, gif, webp)을 확인하고, 파일 시그니처(매직 넘버)로 실제 이미지인지 검사합니다. 파일명은 정리(sanitize)하고, `Content-Length` 기준으로 5MB를 넘으면 본문을 읽기 전에 거부합니다.
- **마이클 리포트**: 외부 패키지 없이 Excel 97-2003 `.xls`의 통합 문서와 BIFF8 시트를 읽습니다. 최대 10MB로 제한하고, 차량·날짜·항목별 원본 지문으로 재가져오기 중복을 방지합니다. 가져온 기록은 `vehicle_records`에 저장됩니다.
- **중복 파일명**: 이미 있는 파일은 덮어쓰지 않고 `_YYYYMMDD_HHMMSS`를 붙입니다. 같은 초에 또 겹치면 `_1`, `_2`…를 붙입니다. 배타적 생성(`open(..., "xb")`)을 써서 동시에 업로드해도 기존 파일이 덮어써지지 않습니다.
- **중복 예약 방지**: 부분 유니크 인덱스(`status != 'CANCELLED'`)를 사용해 동시에 요청이 들어와도 같은 시간대에 예약이 두 건 생기지 않습니다.
- **결제 정보**: 카드번호 전체는 저장하지 않고 끝 4자리만 남깁니다(`신용카드 (**** 1234)`).
- **CSRF 방어**: 모든 POST에서 `Sec-Fetch-Site`(없으면 `Origin`)를 검사해 다른 사이트에서 보낸 요청을 403으로 거부합니다. curl처럼 두 헤더가 모두 없는 요청은 허용합니다.
- **결제 대기 만료**: 결제하지 않은 `PENDING` 예약은 15분 뒤 시간대 조회, 예약, 결제 요청이 들어올 때 자동 취소됩니다.
- **연결 타임아웃**: 30초 동안 데이터가 오지 않는 연결은 끊습니다.
- **보안**: 정적 파일은 경로 조작(`../`)을 차단합니다. 화면 출력은 `textContent`로 처리해 XSS를 막고, 업로드 파일 응답에는 `nosniff`와 CSP 헤더를 붙입니다.
- Python 3.13에서 `cgi` 모듈이 제거되었기 때문에 multipart 파싱은 직접 구현했습니다.
